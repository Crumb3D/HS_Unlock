# HS Unlock changelog

7 Days to Die 3.0–3.4. Install on the dedicated server and on every client. Offline only needs the game Mods folder.

**1.2.4** — Runs on 7 Days to Die 3.4, and still on 3.0–3.3 with the same download. It used to refuse to load on 3.4.

**1.2.3** — The prompt says Locked (Pickable) or Locked, and the radial says Use Lockpick. The lockpick timer starts at 10 seconds. If the pick breaks, the next one starts about half a second back from where it broke.

**1.2.2** — A panel unlocks the door and leaves it where it is. A locked door no longer offers Open.

**1.2.1** — The button class loads from the mod assembly. This fixes the startup crash where biomes.xml failed on terrForestGround, and the battery-bank error that followed because blocks never finished loading.

**1.2.0** — The same switch or panel that unlocked a door locks it again on the next click, and shuts it if it was open.

**1.1.0** — Job-end buttons unlock the loot door and leave it shut. OpenOnUnlock in HSUnlockSettings.json also opens it. Locked doors that are not trader doors take a lock pick. POI switches and pipe-valve switches craft and wire like the vanilla switch.
